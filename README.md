# Results from the paper: Evaluating the Efficacy of AI Agents in Producing High-Quality Portuguese Literacy Items for High-Stake Assessments

This repository holds the item sets generated in the study and the expert evaluations of
those items. The material is organized in two stages:

1. **Preliminary study** — an exploratory generation round with single-model prompting
   (several models × prompting strategies), followed by a screening in which experts kept
   only the items worth evaluating in depth.
2. **Multi-agent study** — the final generation round, produced by the multi-agent system.
   These are the results reported as the paper's main findings.

All items are plain-text files in Portuguese and follow the same layout: assessed skill
(*Competência Avaliada*), command (*Comando*), stimulus / support material
(*Texto de Suporte*), question stem (*Pergunta*), four alternatives (*Opções*, with the
answer key marked by `->`), and the per-alternative rationales (*Justificativas*).

Two skills from the reference literacy matrix are covered:

| Skill ID | Grade | Target skill |
| --- | --- | --- |
| `CL22-3EF-CL02` | 3rd grade (3EF) | Recognizing logical-discursive relations of **causality** marked by the most common conjunctions (letters) |
| `CL22-5EF-CL33` | 5th grade (5EF) | Recognizing logical-discursive relations of **condition** marked by the most common conjunctions (news reports) |

## Repository contents

### `PRELIMINARY_STUDY_ITEMS/`

Items from the preliminary (single-model) study.

- **`ALL_ITEMS/`** — the full initial generation: 206 items, before any screening.
  File names encode the generation setting:
  `<skill>_<model>_<prompting strategy>_<run index>.txt`, e.g.
  `CL223EFCL2_gpt-4.1_CoT_Ep_fewshot_suporte_3.txt`.
  - models: `gpt-4.1`, `gemini-2.0-flash`, `deepseek-chat-v3-0324`
  - strategies: `baseline`, `fewshot`, `CoT`, `Ep` (expert persona) and their
    combinations; the `suporte` suffix marks runs in which the stimulus
    (support material) was supplied to the model instead of being generated by it.
- **`ITEMS_ACCEPT/`** — the 60 items that passed the expert screening of `ALL_ITEMS` and
  were therefore submitted to the full evaluation. 35 of them keep the original
  generation file name; the remaining 25 use the shorter
  `<model>-<batch><variant>.txt` convention (`gpt-`, `gemini-`, `ds-`).

### `MULTI_AGENT_BASED_ITEMS/`

Items produced by the multi-agent system — the final results of the study.
File names follow `<item number>_<variant>.txt`, and the `Origem` line in each file points
back to the generation output (`<n>_saida.json`) the item came from.

- **`CL22_3EF_CL02/`** — 50 items for the 3rd-grade causality skill (lower complexity).
- **`CL22_5EF_CL33/`** — 70 items for the 5th-grade condition skill (higher complexity);
  50 of them (`06_A`–`70_A`) were submitted to expert evaluation.

### Evaluation spreadsheets (CSV)

Each CSV holds one row per evaluated item, with the expert judgement for each quality
criterion plus a free-text `Observation` column. The criteria columns are:

- Is the stimulus (support material) appropriate?
- Does the prompt reflect the assessed skill?
- Is the correct answer accurate?
- Is there a single correct answer?
- Is there parallelism among the alternatives?
- Are the distractors plausible?
- Are the justifications coherent?
- Whether the alternatives rely only on elements present in the stimulus
- Is the item adequately aligned with the assessed skill?
- Could the item be used in an assessment with little or no modification?

| File | Stage | Items covered |
| --- | --- | --- |
| `Preminary_study_finalTableResult.csv` | Preliminary study | the 60 items in `PRELIMINARY_STUDY_ITEMS/ITEMS_ACCEPT/` |
| `Lower_complexity_items_MULTI_AGENT_BASED.csv` | Multi-agent study | the 50 items in `MULTI_AGENT_BASED_ITEMS/CL22_3EF_CL02/` (`CL22-3EF-CL02`) |
| `Higher_complexity_items_MULTI_AGENT_BASED.csv` | Multi-agent study | 50 items from `MULTI_AGENT_BASED_ITEMS/CL22_5EF_CL33/` (`CL22-5EF-CL33`) |

The `Name` column of every CSV matches the corresponding item file name, so each
evaluation row can be traced back to the item it refers to.

> Note on the polarity of one column: in the preliminary-study CSV the criterion is phrased
> as *"Do the alternatives include only elements present in the stimulus?"* (desirable
> answer: `TRUE`), whereas in the multi-agent CSVs it is phrased as *"Do the alternatives
> include elements not present in the stimulus?"* (desirable answer: `FALSE`).
